## Features

- **80 artwork cards** across 7 curatorial collections
- **Hash-based routing** — direct links to artwork detail views work on GitHub Pages
- **Filtering** by availability, collection, and keyword search
- **Artwork detail modals** with dimensions, descriptions, status, enquiry buttons
- **Prints section**
- **Events page** distinguishing current from past
- **Prototype enquiry form** (no email delivery)
- **Mobile responsive**
- **Reduced motion support**

## Hero Image

**Top End of Lake Hawea, New Zealand** — Selected as hero for its wide composition, strong emotional impact, and representation of Susan's broader work beyond France. Sold work (355×265 mm). Source description: "Land of the Long White Cloud — home of my family."
